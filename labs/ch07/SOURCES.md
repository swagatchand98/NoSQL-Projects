# Public metadata and source gap

The chapter reuses the app's attributed Ubuntu advisory metadata and creates a real MongoDB archive during its run. CTI Digest (https://ctidigest.com/) is the assigned discovery reference. Its public page was reachable during research but returned a client-rendered shell rather than identifiable report entries. The bundled dump therefore does not claim to be a CTI Digest export. Obtaining attributed metadata from that source remains an external-data gap.

The named annual-security-reports source has multiple plausible repositories. Set ANNUAL_REPORTS_URL to the faculty-selected listing (raw Markdown or HTML). The read-only check deduplicates canonical links and compares year labels using REPORT_MIN_YEAR; it does not claim day-level publication chronology from a year label or download report binaries.
